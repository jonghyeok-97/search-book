# 규모 추정
- MAU 1천만 가정
  - DAU: 비즈니스에 따라 설계와 시나리오가 달라지지만 보통 10% => 100만
  - QPS/TPS
    1. QPD(Query per Daily) 를 먼저 구한다.
      - 하루에 도서 검색 1회, 도서 저장 1회로 총 2번의 쿼리가 세션마다 발생한다고 가정
      - QPD = DAU * 세션당 쿼리 = 100만 * 2 = 200
    2. QPS/TPS 구한다.
      - QPS/TPS = QPD / 86,400 -> 11.57TPS
    3. 피크타임 TPS 를 구한다.
       - 보통 TPS * 1.2(추정치), 피크타임에 몰리면 2배 3배 곱한다.
  - Volume:
    - ID: 8byte
    - 검색어: 50byte(추정)
    - 검색 시간: 8byte
    - meta: 64byte(추정)
    - 130byte * 100만(DAU) = 하루에 1억 3천 byte (약 130MB)
